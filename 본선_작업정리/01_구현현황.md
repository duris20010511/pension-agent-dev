# 01. 구현 현황

## 서버 경로 (`src/server.py`)

- 대회 규격: `GET /answer`, `GET /health`
- 대화 기억: `POST /session`, `GET·DELETE /session/{id}` (조회·삭제는 점검용 설정에서만)
- 시연: `GET /demo`, `POST /chat`(빠른·정밀 모드, 응답 4칸, 오케스트레이터 단계, 숫자 대조), `GET /alerts/profiles`, `POST /alerts`, `GET /alerts/outbox`, `POST /diy`, `GET /rules`, `GET /ontology`
- 개인정보 가림: 답과 근거에서 주민번호·휴대폰번호 꼴을 가립니다(`_PII_OUT`)
- 운영 로그: `logs/queries-YYYYMMDD.jsonl`에 질문·재작성·답이 쌓입니다. 주민번호·전화번호 꼴만 가리고, `.gitignore`로 제외됩니다. 시연 리허설 질의도 남으니, 본선 서버로 옮길 때와 대회가 끝난 뒤 처리 방법을 정해야 합니다.

## 시연 서버 띄우기 (로컬)

`.claude/launch.json`의 `pension-agent` 설정과 같습니다.

```bash
python -X utf8 -m uvicorn server:app --app-dir src --host 127.0.0.1 --port 8080
```

브라우저에서 `http://127.0.0.1:8080/demo`를 엽니다. 본선 서버는 새로 만들어야 하고 아직 만들지 않았습니다(10-07 결정).

## 본선 서버 배포 주의

`배포가이드.md`와 `API명세.md`는 예선 커밋 뒤로 고쳐지지 않았습니다. 그대로 따르면 다음 문제가 생깁니다.

- 가이드의 tar 명령에 `data/`가 빠져 있어 Dockerfile의 `COPY data/`가 실패합니다. 지금은 `data/`(펀드 카드·온톨로지·문서 꼬리표)가 꼭 필요합니다.
- `.cache`가 지금 426MB입니다. 가이드는 93MB라고 적혀 있고, 옛 캐시까지 섞여 있습니다. v3 캐시만 골라 넣어야 합니다.
- 가이드의 응답 시간(평균 65.0초, 최대 108.9초)은 예선 서버 값입니다. 본선 서버에서 다시 재야 합니다.
