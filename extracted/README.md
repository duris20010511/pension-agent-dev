# 추출본 (extracted/)

원본 데이터(`2.연금/2.연금/docs.zip`, `투자설명서.zip`)의 전체 텍스트 추출 결과.
원본 zip은 그대로 두었고, 여기에는 텍스트만 들어 있다.

## 구성

| 경로 | 내용 |
|---|---|
| `docs/doc*.txt` | 제도·세제 안내문서 58건 (284,245자) |
| `prospectus/KR*.txt` | 펀드 투자설명서 100종, 6,425페이지 (8,704,570자) |
| `_manifest.csv` | 파일별 원본·추출방식·페이지수·문자수·보완여부 |

총 **8,988,815자**.

## 파일 형식

각 txt 최상단에 헤더:
```
# 원본: docs_renamed/doc10.pdf
# 추출방식: pymupdf
```
본문은 `[페이지 N]` 마커로 페이지 구분. 표는 `셀 | 셀` 형식.

## 추출 방식

1. **스크립트 추출** — pymupdf / python-docx / openpyxl / python-pptx
2. **vision-transcription** — 텍스트 레이어가 없는 이미지 PDF 20건을 페이지 이미지로 렌더링해 전사
   (doc1~5, doc7~9, doc21, doc22, doc24, doc27, doc28, doc30~32, doc37, doc53, doc54, doc56)
3. **부분 보완 전사** — 텍스트는 뽑혔지만 일부 내용이 이미지로 박힌 경우, 해당 부분만 전사해 파일 끝에 섹션으로 추가
   - `[포함 이미지 전사]` — DOCX/PPTX 삽입 도표·순서도·화면캡처 33장 (doc6, doc26, doc33, doc44, doc55)
   - `[이미지 페이지 전사]` — 투자설명서 32종의 이미지 표 88페이지 (재무상태표·손익계산서·자산구성 차트·설정환매현황 등), docs 2건
   - doc57, doc58은 해당 페이지를 전사본으로 대체

이미지 페이지 탐지는 2단계로 했다. 1차는 큰 이미지 기준, 2차는 페이지 면적 대비 이미지 커버리지 35% 이상 + 텍스트 밀도 기준. doc57처럼 글자가 수십 개 이미지 조각으로 쪼개진 경우는 1차에서 걸리지 않아 2차 기준이 필요했다.

## 사용 시 주의

- **판독불가 표기**: 원본이 마스킹·잘림인 부분은 `(판독불가)`로 표시. 현재 **35건**이며 doc7(채권 종목명·코드) 33건, doc33(워터마크 겹침) 2건이다. 전부 원본 자체의 한계라 복구 불가. 확인용 고해상도 이미지와 항목별 목록은 `../미판독문서/` 폴더 참조.
  - KR5113450111 p49 기준가격은 `936(판독불가)`로 전사됐으나 재검증 결과 **995원**으로 확정해 수정했다.
- **원문 오탈자 보존**: 요약·교정 없이 원문 그대로 전사했다. doc27 '퇴직충담금', doc30 '(후추)', doc31 'IPR', doc8 '배당안수주대금입금' 등은 원본 표기.
- **중복 문서**: doc46~50은 중도인출 사유별 문서로 앞 문단이 동일하다. 청크 단위 중복 제거 시 사유 구분이 사라지므로 주의.
- **보완 섹션 위치**: 이미지 전사 섹션은 파일 끝에 모여 있고, 본문 흐름 순서와는 다르다. 청킹할 때 `[페이지 N]`과 `[페이지 N — 전사]`를 같은 페이지로 묶어야 한다.
- **워터마크 제외**: 일부 이미지 배경의 유출방지 워터마크(숫자·IP·날짜)는 문서 내용이 아니므로 전사에서 제외했다.
- **구조화 데이터**: `docs/doc29.txt`(디폴트옵션 FAQ 100선)는 원본이 xlsx다. 컬럼 구조를 살리려면 원본 `doc29.xlsx`를 직접 파싱하는 편이 낫다. `doc34.xlsx`(실물이전 불가사유)도 마찬가지.
- **doc19**는 314자로 짧지만 원본 자체가 1페이지 짧은 안내문이라 누락이 아니다.
