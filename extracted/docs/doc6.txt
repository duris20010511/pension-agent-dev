[개인IRP 부담금 입금]

가. 부담금 유형

[표]
부담금유형 | 설명
가입자부담금 | 가입자가 직접 납입하는 금액 (연간 1,800만원까지 납입가능/연금저축 납입금액 합산하여 최대 연 900만원까지 세액공제 가능)
만기ISA전환금 | 만기 해지된 ISA 지급액을 개인IRP로 전환입금한 금액

가입자부담금은 IRP계좌번호로 입금하는 동시에 자동신탁매수 처리

*유의사항

가. IRP대표계좌번호로 입금이 불가한 경우

▶입금업무시간(08시~16시) 외 입금하는 경우

▶연금 개시된 IRP인 경우

▶납입가능한도를 초과하여 입금하는 경우

▶플랜등록 전, 계약이전 혹은 계약해지 처리중인 경우

나. 부담금 납입결과 안내

1) 발송대상 : 가입자

2) 발송매체 : E-Mail / SMS

3) 발송시기 : E-Mail_ 부담금 입금 후 상품 매수 완료일 + 1영업일

SMS_부담금 입금일 + 1영업일

다. 유의사항

1) 투자비율 미등록 가입자의 경우 현금성자산으로 입금 가능

2) DC/개인IRP 가입자부담금 입금금액은 연금저축(최대 600만원)과 합산하여 연간 최대 900만원까지 세액공제 가능

3) 개인IRP 계약의 최초 부담금 입금 시 소득세법 상의 가입일자가 확정됨에 따라 신중한 업무 처리 필요

※ 계약의 최초 입금은 입금 취소 불가

5. 입금취소

가. 개요

입금 당일 한해 취소 신청 가능

나. 업무처리 가능시간

부담금입금취소(10억초과) : 08:00 ~ 15:00 / 부담금입금취소(10억이하) : 08:00 ~ 16:00

다. 업무처리방식

1) 취소가능여부 ‘불가능’인 대상은 운용지시 주문완료 건으로 운용지시 취소 후 입금 취소 가능

단, WRAP 가입자는 일임계약 대상이므로 운용지시 취소가 불가하며, WRAP 해지 후 운용지시 취소 가능

2) 개인IRP 가입자부담금 입금취소는 유선 접수 가능

라. 유의사항

1) DB/DC 입금취소는 부담금 입금 처리부점에서만 취소 가능

2) 플랜기준의 최초 입금 건은 취소 불가

3) DC/개인IRP의 일시전환금은 취소 불가

4) DB 부담금 입금 취소 시 입금으로 인해 변경된 적립비율이 이전 비율로 원복 처리됨

6. 납입한도 관리

가. 납입한도

1) 연금저축과 DC/IRP 합산하여 연간 1,800만원까지 한도 설정 가능

2) 전 금융기관 합산 적용

[퇴직연금 만기 ISA 전환입금]

1. 업무개요

가. ISA 만기해지금액의 전부 또는 일부를 만기일로부터 60일 이내 개인IRP로 입금가능

- ISA 유형에 상관없이 가입기간 3년 이상이면 해지한 금액을 연금계좌로 전환입금 가능

2. 전환신청 접수

가. 전환신청 접수 - 내점/유선 모두 가능

1) 전환가능금액 조회 (비밀번호 입력 조회 시 은행연합회에 정보를 확인함)

① ISA만기금액 : 60일 이내 만기해지된 ISA 지급액 (60일은 캘린더 기준, 만기일자 불산입)

② 기전환금액 : ISA만기금액 중에서 이미 연금계좌로 전환 입금된 금액

③ 미사용금액 : 현재 만기ISA전환 가능금액

2) 전환신청금액 등록

3) 알림톡/문자 자동발송(신청결과 및 입금계좌번호 안내)

나. 전환신청이 불가한 경우

1) 연금개시 계좌

2) 동일계좌에 처리가 완료되지 않은 전환입금 신청 건이 있는 경우

다. 전환신청 취소 : 전환입금 완료 전까지 신청취소 가능

2. 전환 입금처리

가. 만기ISA 전환금 입금

1) 개인IRP계좌번호 + 22로 입금

나. 전환 입금처리

① 입금처리가 완료되면 만기ISA전환입금일 정보가 은행연합회에 전송됨

② 신청일이 ISA만기일로부터 60일 이내 더라도 입금처리일이 60일을 경과했다면 처리불가

- 신청 당일 입금처리까지 완료하는 것을 권장

- 부득이하게 당일 입금처리가 어려운 경우 고객에게 60일 이내 입금

③ 전환신청금액과 다른 금액으로 입금처리 불가

- 최종 입금할 금액이 전환신청금액과 다르면 전환신청 취소 후 새로 신청해야 함

다. 입금취소 불가

3. 만기ISA 전환금의 세액공제

1) 만기ISA 전환 납입액의 세액공제대상금액 (ISA전환금액, IRP납입액은 순납입액 기준)

= Min (*세액공제한도, ISA전환금액+IRP납입액)

* 세액공제한도 = Min (300만원, 전환납입액의 10%) + Min (ISA전환금액+IRP납입액, 900만원**)

2) 연속되는 2개 연도에 각각 나누어 전환 입금을 한 경우에도 인당 최대 공제한도는 300만원

4. 유의사항

1) ISA 만기일로부터 60일이 경과한 경우 전환불가

- 신청일이 ISA만기일로부터 60일 이내 더라도 입금처리일이 60일을 경과했다면 처리불가

2) ISA전환 입금 전용계좌번호는 개인IRP계좌번호 + 22

3) 전환신청 취소는 입금확인 완료 전까지 가능

4) 인출순서 : 당해 가입자부담금 → 당해 만기ISA 전환금 →기타비과세재원 → 이연퇴직소득 → 세액공제대상&운용수익
