## 답변 품질에 미치는 영향

doc7 은 채권 상품 목록 화면이고, 가려진 것은 **개별 종목명과 종목코드**다.
수익률·위험등급·잔존기간·투자한도 같은 **판단에 쓰이는 값은 모두 읽혔다.**
doc33 은 워터마크에 가린 2건이며 주변 문장으로 내용이 파악된다.

연금 상담 질의는 제도·세제·상품 속성을 묻지 개별 채권 종목명을 묻지 않으므로,
이 35건이 답변 가능 범위를 좁히지는 않는다.
